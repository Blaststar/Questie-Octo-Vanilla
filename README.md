Simple lightweight featureful quest tracker for OctoWoW
Make sure you rename folder to **Questie-Octo** after extraction

If you notice any missing quests, objective locations, or notice wrong map icon locations feel free to use [UnitLogger](https://github.com/Blaststar/UnitLogger) addon to help speed up fixes/development

**ClassicAPI.dll** needed.

[Latest release here.](https://github.com/brues-code/ClassicAPI/releases/latest)
